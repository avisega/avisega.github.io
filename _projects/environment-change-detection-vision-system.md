This patented system introduces an early vision-based framework for detecting and interpreting changes within a physical environment using a single camera and display pair. The method compares captured images against known reference frames to identify motion, object presence, and shape changes without relying on external sensors or markers. By dynamically modeling background and lighting conditions, the system extracts silhouettes and movement trajectories in real time, enabling seamless interaction with projected or displayed visual content. Originally designed for interactive public installations and advanced motion interfaces, this work anticipated key principles later used in immersive displays, gesture control, and adaptive vision systems.
