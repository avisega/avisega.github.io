This project developed a real-time AI system for monitoring multi-user interactions and identifying critical moments that require human attention. The framework integrates shallow natural language processing with visualization tools to detect and classify conversational states such as consensus formation, inactivity, or technical challenges. These are surfaced to a human operator through an adaptive alert dashboard, enabling effective oversight across multiple concurrent sessions. The system architecture combines message-level classification, temporal pattern detection, and event visualization, supporting scalable human-AI collaboration in complex communication environments. Evaluations in live settings demonstrated that the system achieved expert-level recognition accuracy while improving the efficiency and quality of human interventions.
