This project introduces a ranking-based framework for personalizing information sequencing using collaborative filtering and social choice theory. Instead of predicting user performance or preferences directly, the system constructs individualized difficulty rankings by aggregating multiple behavioral signals—accuracy, retries, and response time—across similar users. The approach, called EduRank, combines ranking aggregation from recommender systems with weighted voting mechanisms from computational social choice, enabling fine-grained personalization without relying on absolute scores. Tested on large-scale behavioral datasets, the method outperformed standard ranking and matrix factorization approaches, showing how ordinal data and user similarity can be leveraged to optimize personalized content ordering in any domain where difficulty or complexity must be adapted dynamically to the individual.
